  WezTerm 操作ガイド（Windows向け・keybinds.lua反映済み）

----------------------------------------------------------------
【タブ管理】
----------------------------------------------------------------

  新規タブ作成          Alt + T
  タブを閉じる          Alt + W
  次のタブへ移動        Ctrl + Tab
  前のタブへ移動        Ctrl + Shift + Tab
  タブ番号で移動        Alt + 1〜9
  タブを左に入れ替え    Leader → {
  タブを右に入れ替え    Leader → }

----------------------------------------------------------------
【ペイン管理（画面分割）】  Leaderキー = Ctrl + Q
----------------------------------------------------------------

  上下に分割            Leader → D
  左右に分割            Leader → R
  ペインを閉じる        Leader → X
  ペイン移動（左）      Leader → H
  ペイン移動（右）      Leader → L
  ペイン移動（上）      Leader → K
  ペイン移動（下）      Leader → J
  ペインを選択          Ctrl + Shift + [
  選択ペインのみ表示    Leader → Z（ズームトグル）

----------------------------------------------------------------
【ペインサイズ調整】  Leader → S で調整モードに入る
----------------------------------------------------------------

  左に縮小              H
  右に拡大              L
  上に縮小              K
  下に拡大              J
  調整モード終了        Enter

----------------------------------------------------------------
【コピーモード】  Leader → [ で開始 / Q or Escape で終了
----------------------------------------------------------------

■ 移動
  左右上下              H / L / K / J
  行頭へ（空白含む）    0
  行頭へ（空白除く）    ^
  行末へ                $
  単語の先頭へ進む      W
  単語の先頭へ戻る      B
  単語の末尾へ進む      E
  一番上へ              G
  一番下へ              Shift + G
  ビューポート上端      Shift + H
  ビューポート下端      Shift + L
  ビューポート中央      Shift + M

■ スクロール
  1ページ上             Ctrl + B
  1ページ下             Ctrl + F
  半ページ上            Ctrl + U
  半ページ下            Ctrl + D

■ 範囲選択
  文字単位選択          V
  行単位選択            Shift + V
  矩形選択              Ctrl + V

■ コピー・終了
  クリップボードにコピー  Y
  コピーして終了          Enter
  コピーモード終了        Q or Escape or Ctrl + C

----------------------------------------------------------------
【クリップボード】
----------------------------------------------------------------

  コピー                Alt + C
  貼り付け              Alt + V

----------------------------------------------------------------
【ワークスペース】  ※タブより上位の概念（複数ウィンドウ相当）
----------------------------------------------------------------

  ワークスペース切り替え    Leader → W
  ワークスペース名変更      Leader → $
  新規ワークスペース作成    Leader → Shift + W

----------------------------------------------------------------
【ランチャーメニュー / コーディングレイアウト】
----------------------------------------------------------------

  ランチャーメニューを開く      Leader → M
    （config.launch_menuの一覧: PowerShell / WSL / Neovim / Claude Code）
  コーディングレイアウトを開く  Leader → N
    （新規タブに 左:Neovim 右:Claude Code の2ペインを自動生成）

----------------------------------------------------------------
【ハイパーリンク】
----------------------------------------------------------------

  URL・メールアドレス・Windowsの絶対パス（C:\...）が
  Ctrl+クリックで開けるようになっている（config.hyperlink_rules）

----------------------------------------------------------------
【Muxサーバー（永続セッション）】
----------------------------------------------------------------

  Muxドメイン"mux"へアタッチ          Leader → Shift + M
    （閉じる前のタブがあれば復元される。tmuxのattach相当）

  ※ 通常起動（アイコンクリック等）では自動接続しない。
    起動時に自動connectする設定は apply_default_size が効かなくなり
    ウィンドウが小さく開く不具合が出たため廃止（2026-07-22）。
  ※ Leader → N のコーディングレイアウトは"mux"ドメインに作られるため、
    ウィンドウを閉じてもプロセスは生きている。戻る時は上記アタッチを使う。
  ※ 完全に終了させたい場合はタスクマネージャーで
    wezterm-mux-server.exe を終了する。

----------------------------------------------------------------
【その他】
----------------------------------------------------------------

  フォントサイズ拡大    Ctrl + +
  フォントサイズ縮小    Ctrl + -
  フォントサイズリセット  Ctrl + 0
  フルスクリーン切り替え  Alt + Enter
  コマンドパレット      Ctrl + Shift + P  または  Alt + P
  設定再読み込み        Ctrl + Shift + R

----------------------------------------------------------------
【Leaderキーについて】
----------------------------------------------------------------

  Leaderキー = Ctrl + Q（2秒以内に次のキーを押す）
  tmuxのprefixキーと同じ考え方。
  例: 上下分割 → Ctrl+Q を押してから D を押す

----------------------------------------------------------------
【現在の設定の特徴（wezterm.lua）】
----------------------------------------------------------------

  ・背景透過             有効（opacity: 0.85）
  ・ぼかし               Acrylic（Windows専用）
  ・カラースキーム       Tokyo Night
  ・フォント             JetBrainsMono Nerd Font Mono
  ・起動時               最大化
  ・タイトルバー         非表示（RESIZE モード）
  ・タブ追加ボタン（+）  非表示
  ・タブ閉じるボタン（×）非表示（nightly版）
  ・タブ1つの時          タブバー自動非表示
  ・アクティブタブの色   黄色（#ae8b2d）
  ・非アクティブタブの色 グレー（#5c6d74）
