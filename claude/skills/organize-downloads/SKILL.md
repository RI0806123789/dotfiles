# Downloads整理スキル

`C:\Users\liang\Downloads` の中身を、`C:\Users\liang\Documents\KIT\` の整理体系へ振り分ける。
**最重要ルール: 何をどこへ移動したか、必ず全ファイル分を明記して報告する。**

## 手順

1. **一覧化**: `ls -la` で Downloads の中身を全て把握する。
2. **格納先構成の確認**: メモリ `kit_directory_structure` を参照しつつ、実際の `Documents\KIT\01_Grade\02_2nd\01_1stSemester\` 配下の科目フォルダ・週フォルダ（第1回〜第15回）の**現状を必ず実地確認**する（メモリは古い場合がある）。在籍学期は都度確認（2026-07時点は2年1学期 = `02_2nd\01_1stSemester`）。
3. **各ファイルの帰属判定**: 下記「振り分けルール」でファイル名・内容から格納先を決める。PDFは `pdftotext` で内容を確認して裏取りする。
4. **重複・衝突チェック（重要）**: 格納先に同名/類似名ファイルがある場合、`sha256sum` で**ハッシュ比較**する。
   - 完全一致 → 格納先を正としDownload側を削除。
   - 内容が違う（下書き/旧版など）→ 格納先の既存を `_旧版(日付)` 等にリネームして退避してから新版を配置し、データを失わない。
   - 名前が衝突しない別ファイルなら、上書きせずそのまま併置。
5. **移動**: `mv -n`（no-clobber）で移動。新規フォルダが要る場合は `mkdir -p`。
6. **検証**: 移動元が空になったか・移動先に入ったかを `ls` で確認。
7. **報告**: 全ファイルの移動先を表形式で明記。据え置いたもの（システムファイル等）も理由付きで明記。
